## Clock

| Signal | Pin | Notes |
|--------|-----|-------|
| `clk_27m` | 52 (`XTAL_IN`) | On-board **27 MHz** crystal |

Phase-1 sample clock target is **~100 MHz**, generated by rPLL from 27 MHz.

Exact 100.000 MHz is not reachable with a single Gowin rPLL stage
(`FBDIV` max 64). Closest practical setting:

```
Fout = 27 MHz × 33 / 9 = 99 MHz
IDIV_SEL = 8   (÷9)
FBDIV_SEL = 32 (×33)
ODIV_SEL  = 0  (÷1)
```

Host `sample_rate` is therefore based on **99_000_000 Hz**, with an
integer sample-enable divider for lower rates.

## USB-UART (BL702 debugger)

Schematic mapping:

| FPGA pin | Net | Direction (FPGA) | BL702 |
|----------|-----|------------------|-------|
| 17 | `FPGA_TX` / `IOB2A` | output | `BL_UART1_RX` |
| 18 | `FPGA_RX` / `IOB2B` | input  | `BL_UART1_TX` |

Phase-1 baud: **115200 8N1**.

## Capture RAM budget

`8 × 16384 × 1 bit = 128 Kbit` fits comfortably in BSRAM (~7 of 26 blocks).
`16 × 8192` uses the same budget (parameterized).
